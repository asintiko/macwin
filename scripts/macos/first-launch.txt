MacWin — first launch / первый запуск

Requires macOS 15 or later on Apple Silicon (M1 or later).

Install / установка
  Double-click "Install MacWin.command" (right-click > Open if macOS asks).
  It copies MacWin to Applications, prepares it for this Mac and opens it.
  Simplest of all, without the dmg, in Terminal:
    curl -fsSL https://github.com/djjdjdkdjdvdvd/macwin/releases/latest/download/install-macos.sh | bash

  If macOS says "Apple could not verify MacWin" (a test build dragged to
  Applications by hand), run the installer above instead, or choose
  System Settings > Privacy & Security > Open Anyway.

Set up / настройка
  1. In the MacWin window choose "Primary" / «Основной» (its keyboard and
     mouse control the other computer).
  2. Drag the second computer to where it stands next to your screens.
  3. On the Windows PC open MacWin and choose "Secondary" / «Вторичный»;
     enter the code it shows here.

Permissions / разрешения
  Allow Local Network access when macOS asks. The MacWin window shows the
  state of Accessibility and Input Monitoring and opens the right page of
  System Settings: enable MacWin there, then reopen MacWin. If macOS asks
  for clipboard access, allow it (Paste from Other Apps).

Closing the window keeps MacWin running in the menu bar; quit it from the
menu bar icon. Emergency release: Control+Option+Shift+Esc.
