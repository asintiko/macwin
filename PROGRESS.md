# Прогресс MacWin

Обновлено: **16 октября 2026**.

Цель — один набор клавиатуры, мыши и буфера обмена для MacBook и Windows-ноутбука
в одной сети. Версия **0.2** превращает MacWin из меню в трее в обычное приложение
с окном: выбор ролей «основной / вторичный», расстановка экранов перетаскиванием и
сопряжение вводом кода. План и статус этапов — в [PLAN.md](PLAN.md).

Работа ведётся в ветке `hoplite/emporion-50969eff` (форк `djjdjdkdjdvdvd/macwin`).
Тестовые сборки публикуются в [последнем выпуске](https://github.com/djjdjdkdjdvdvd/macwin/releases/latest);
установка — в [README](README.md#installing) и [FIRST_RUN.md](FIRST_RUN.md).

## Готовность

Этапы 1–7 плана из 8 сделаны и проходят CI на Linux, macOS и Windows; выпуск
публикуется автоматически. Не сделан только этап 8 — проверка на настоящих
MacBook и Windows-ноутбуке (её можно провести только на этих компьютерах) и
исправление того, что она найдёт.

## Выпуски

Выпуск по тегу `v*` собирает и публикует CI, только если прошли все проверки;
ссылки `releases/latest/download/…` ведут к последнему выпуску.

совпали, EXE — 64-битная GUI-программа для Windows, в ZIP все файлы установщика,
подпись приложения в DMG проверена в CI.

## Где остановились и что восстановлено

Предыдущая сессия успела сделать этап 1 (ядро и протокол расстановки), крейт
`macwin-ui` (окно, мастер, редактор расстановки) и описать сценарий, но не
подключила окно к агенту. Её коммиты лежали только во временных снимках
`refs/hoplite/wip/thr_295207144f07476fb6d0e9ef57f14d73/*` репозитория `asintiko/macwin`. Ветка
перемотана на последний настоящий коммит `d123238`, а незакоммиченная часть
(роль, расстановка и язык в `config.toml`, тексты трея на двух языках, доработки
окна) сохранена отдельными коммитами.

## Сделано в версии 0.2

**Окно и сценарий** (этапы 3–5). Мастер первого запуска: «Каким будет этот
компьютер?» → у основного — расстановка и ввод кода, у вторичного — крупный код и
ожидание. Главное окно: статус и пауза, вкладки «Расстановка», «Буфер обмена»,
«Настройки» (автозапуск, Cmd↔Ctrl, поиск в сети, язык, разрешения macOS),
«О программе»; отвязать партнёра, сменить роль, настроить заново. Русский и
английский.

**Роли и сопряжение** (этап 2). Вторичный показывает код и слушает; основной
вводит код (или адрес вручную), подключается и хранит расстановку. После ввода
кода оба сразу переходят в «Подключено», без вопроса о стороне. Вторичный
получает расстановку основного в каждом `Hello` и показывает её.

**Расстановка** (этапы 1 и 4). Экран партнёра пристыкован к конкретному монитору
основного с любой стороны и со смещением; курсор переходит только там, где экраны
соприкасаются. Редактор показывает мониторы этого компьютера, а после подключения —
реальные экраны партнёра; изменение применяется без перезапуска приложения.

**Один процесс, трей, Dock, автозапуск** (этап 6). Окно на главном потоке; значок
в строке меню macOS живёт в его цикле событий, значок в трее Windows — в своём
потоке. Закрытие окна оставляет MacWin в фоне; меню значка: статус, «Открыть
MacWin», пауза, выход. На macOS значок в Dock виден, пока открыто окно; повторный
запуск из Finder/Dock показывает окно. На Windows щелчок по значку или повторный
запуск показывает окно уже работающей копии. Автозапуск при входе —
`--background`: без окна, только значок; запись автозапуска от 0.1 (без
`--background`) при первом запуске 0.2 обновляется сама, а записи других копий
не трогаются. Если OpenGL недоступен, остаётся прежнее меню трея.

**Разрешения macOS.** При обычном запуске (не автозапуске) MacWin сам вызывает
системные запросы «Универсальный доступ» и «Мониторинг ввода»: без этого macOS не
показывает приложение в списках Системных настроек и его пришлось бы добавлять
кнопкой «+». Окно показывает состояние разрешений (проверка каждые 2 с) и
открывает нужный раздел настроек; общий доступ возобновляется сам, когда
разрешения выданы. `macwin run` (режим командной строки) тоже учитывает роль и
расстановку.

**Сборка и установка** (этап 7).
- macOS: одна команда в Терминале (`install-macos.sh`) скачивает DMG через `curl`
  (без карантина — Gatekeeper не спрашивает), закрывает запущенный MacWin
  (команда «Выйти», затем SIGINT, принудительно — только в крайнем случае),
  ставит приложение в «Программы» (`~/Applications`, если нет прав на
  `/Applications`), подписывает тестовую сборку для этого Mac и сбрасывает
  устаревшие разрешения, если подпись изменилась (иначе macOS показывает их
  включёнными, но они не работают). Тот же скрипт — `Install MacWin.command`
  внутри DMG. Проверяет macOS 15+ и Apple Silicon (в том числе в Терминале под
  Rosetta).
- Подпись Developer ID и нотаризация готовы: при секретах `MACOS_CERTIFICATE_P12`,
  `MACOS_CERTIFICATE_PASSWORD`, `APPLE_ID`, `APPLE_TEAM_ID`, `APPLE_APP_PASSWORD`
  CI подписывает с Hardened Runtime, нотаризует и степлит DMG — тогда его можно
  просто перетащить в «Программы» без предупреждений. Без секретов сборка
  остаётся тестовой (ad-hoc).
- Windows: `install-windows.ps1` (`irm … | iex`) скачивает ZIP без пометки
  «из интернета» (SmartScreen не мешает), сверяет SHA-256 и запускает
  установщик: «Пуск», автозапуск в фоне, брандмауэр, окно после установки.
  Есть и отдельный EXE без установки.
- Тег `v*` публикует выпуск из проверенных CI-пакетов с постоянными именами
  файлов, поэтому ссылки `releases/latest/download/…` не устаревают.
- `THIRD_PARTY_NOTICES` в обоих пакетах содержит лицензии шрифтов, которые
  egui встраивает в окно (Ubuntu Font Licence 1.0, Hack — MIT и Bitstream Vera,
  иконки — MIT).
- Версия 0.2.0.

## Проверки

- CI на Linux, macOS 15 и Windows 2025: `cargo fmt`, Clippy `-D warnings`, все
  тесты, `keymap-gen --check`, сборка DMG и Windows EXE/ZIP, установка/обновление/
  удаление Windows-пакета, проверка DMG и `cargo-deny` — все задания зелёные для
  коммитов `53fca68` (окно) и `e7d8399` (установщики).
- Новые тесты: два контроллера проходят сопряжение по ролям через команды окна по
  QUIC на 127.0.0.1 (вторичный получает расстановку, пауза, отвязка), меню трея в
  режиме окна, перевод состояния в модель окна, тексты на двух языках.
- Скриншоты окна сняты под Xvfb с демо-бэкендом: [`docs/screenshots`](docs/screenshots).
- Окно под Xvfb: запуск без окна → окно появляется по запросу; запрос закрытия
  (WM_DELETE_WINDOW) прячет окно, а процесс продолжает работать; повторный запрос
  снова показывает окно. Обработка скрытого окна на Windows (egui#5229) есть в
  исходниках eframe 0.37.
- Скрипты: `bash -n` и ShellCheck без замечаний; PowerShell-скрипты разбираются в CI.
  Логика `install-macos.sh` прогнана на Linux с заглушками команд macOS: установка
  через `curl | bash`, обновление поверх запущенного MacWin со сменой подписи
  (сброс разрешений), установка из DMG.

## Ограничения

- Окно, трей, Dock, Cmd+Q, автозапуск, разрешения и настоящий сеанс на двух
  компьютерах в CI проверяются только сборкой и тестами; на экране — на
  [этапе 8](https://github.com/asintiko/macwin/issues/8) по [FIRST_RUN.md](FIRST_RUN.md).
- Без сертификата Developer ID DMG не нотаризован: устанавливайте командой из
  Терминала. После каждого обновления тестовой сборки macOS заново спрашивает
  разрешения и один раз — доступ к связке ключей («Всегда разрешать»); подпись
  Developer ID это убирает. Windows-программы не подписаны.
- DMG только для Apple Silicon и macOS 15+, Windows — только x64.
- Откат на 0.1 не прочитает `config.toml`, сохранённый 0.2 (новые ключи `role`,
  `language` и `[arrangement]`): удалите их или файл целиком.
- Экран входа, блокировка и UAC Windows не поддерживаются (проект службы —
  `.agents/tasks/phase4-design.md`). Мониторы, подключённые на лету, учитываются
  при следующем подключении.
