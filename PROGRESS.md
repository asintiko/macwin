# Прогресс MacWin

Обновлено: **15 октября 2026**.

Цель ближайшего этапа — подключить MacBook и Windows PC в одной локальной сети:
общие мышь, клавиатура и буфер обмена. Основной код есть, но это ещё не
проверенный на двух настоящих компьютерах релиз.

Изменения публикуются в [PR #1](https://github.com/kojikor/macwin/pull/1),
ветка `hoplite/olynthos-daa5d6c0`. Инструкции: [установка](README.md#installing),
[сопряжение и работа](README.md#usage), [первый запуск и ручной чек-лист](FIRST_RUN.md).

Опубликован [тестовый выпуск `v0.1.0-test.1`](https://github.com/kojikor/macwin/releases/tag/v0.1.0-test.1).
Все три установочных файла пересобраны из проверенного коммита `68bfcdd`: [все шесть заданий CI прошли](https://github.com/kojikor/macwin/actions/runs/38740478878),
включая проверку отсутствия внешнего Visual C++ Runtime у Windows EXE.

- [DMG для Apple Silicon, macOS 15+ (с `Install MacWin.command`, без окна «Не удалось проверить»)](https://github.com/kojikor/macwin/releases/download/v0.1.0-test.1/MacWin-0.1.0-macos-arm64.dmg).

## Ограничения

- Локальная среда — Linux. Здесь запускаются fake-backend и сетевые тесты
  на loopback, но не настоящий захват ввода или буфер обмена. Нативные меню
  и диалоги визуально не проверены; скриншотов с Mac/Windows пока нет.
- Пять пропущенных CLI-тестов требуют macOS или Windows. В матрице этих ОС
  они не пропускаются; Linux отдельно проверяет отказ неподдерживаемой платформы.
- На macOS пропущен тест `keychain_round_trip`, использующий настоящий login keychain.
- DMG из `macos-15` предназначен для Apple Silicon (ARM64) и macOS 15+.
  Это не universal app и не сборка для Intel Mac. Windows-пакет предназначен для x64.
- macOS-приложение подписано ad-hoc, без Developer ID и notarization; Windows EXE
  не имеют распространительной подписи. Gatekeeper и SmartScreen могут предупреждать.
- PowerShell и `cargo-deny` локально не устанавливались: их проверки выполнены в CI.
- Зелёный CI проверяет сборку и автоматические сценарии, но не заменяет живой
  сеанс на двух компьютерах, разрешения ОС и визуальную проверку меню.

## Отдельный последующий этап

Экран входа, блокировка и UAC Windows пока не поддерживаются. Для них существует
[дизайн opt-in SYSTEM-сервиса](.agents/tasks/phase4-design.md), но сервис не
реализован и не нужен для обычного сеанса между уже вошедшими пользователями.

Пакеты пока не имеют распространительной подписи/нотаризации: предупреждения
Gatekeeper и SmartScreen возможны. Они не должны устраняться отключением защиты ОС.
