# Первый запуск MacWin: MacBook ↔ Windows

Это инструкция для проверки на реальных компьютерах ([этап 8](https://github.com/asintiko/macwin/issues/8)),
а не отчёт об уже выполненном запуске. Статус работ — в [PLAN.md](PLAN.md) и [PROGRESS.md](PROGRESS.md).

Версия 0.2 — это обычное окно приложения с мастером первого запуска: роли
«основной/вторичный», расстановка экранов и код. Берите оба пакета из одного
выпуска: [последний выпуск](https://github.com/djjdjdkdjdvdvd/macwin/releases/latest)
(или артефакты CI `macwin-macOS` и `macwin-Windows` одной сборки).

## 1. Подготовить два компьютера

- Оба пользователя вошли в систему; Windows не заблокирована. UAC, экран входа
  и управление приложениями с правами администратора пока не поддерживаются.
- Оба компьютера доступны друг другу в одной доверенной локальной сети.
  Гостевой Wi-Fi, изоляция клиентов, VPN и разные подсети могут мешать соединению.
- На Windows сеть отмечена как **Частная**. Не открывайте порты роутера в интернет
  и не отключайте брандмауэр. Установщик добавляет правила для UDP 47800 и 47801.
- На Mac требуется macOS 15 или новее и Apple Silicon (ARM64, M1 и новее).
  DMG из CI не является universal app и не подходит для Intel Mac.
  Windows-пакет предназначен для x64. Используйте пакеты одной проверенной сборки.
- Для проверки буфера заранее подготовьте несекретный текст, небольшую картинку
  и тестовый файл. Скопированные файлы передаются сразу, а не только при вставке.

## 2. Установить

**MacBook**

1. Откройте **Терминал** (`Terminal.app`) и выполните одну команду:
   ```sh
   curl -fsSL https://github.com/djjdjdkdjdvdvd/macwin/releases/latest/download/install-macos.sh | bash
   ```
   Скрипт скачивает DMG последнего выпуска через `curl` (такой файл macOS не помечает
   карантином, поэтому Gatekeeper ничего не спрашивает), закрывает запущенный MacWin,
   ставит `MacWin.app` в «Программы», подписывает тестовую сборку для этого Mac и
   открывает MacWin. Если подпись изменилась после обновления, скрипт сбрасывает
   старые разрешения «Универсальный доступ» и «Мониторинг ввода»: иначе macOS
   показывает их включёнными, но они не работают, и MacWin просто попросит их заново.
   Тот же скрипт лежит в DMG как **`Install MacWin.command`** (если DMG скачан
   браузером, откройте его правым кликом → «Открыть»).
2. Откроется окно MacWin. Разрешите **Локальную сеть**, когда macOS спросит. На вкладке
   **Настройки** видно состояние разрешений **Универсальный доступ** и **Мониторинг ввода**;
   кнопки открывают нужный раздел **Системных настроек**. Если macOS отдельно спрашивает
   о вставке из других приложений (**Paste from Other Apps**), разрешите и её.
3. После изменения разрешений выйдите из MacWin (⌘Q или **Выйти из MacWin** в строке меню)
   и откройте снова.

Когда в CI будет добавлен сертификат Developer ID (см. README → Packages → Signing),
DMG будет нотаризован: его можно будет просто перетащить в «Программы», без Терминала
и без предупреждений.

**Windows**

1. **Рекомендуемый способ:** откройте **PowerShell** и выполните:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://github.com/djjdjdkdjdvdvd/macwin/releases/latest/download/install-windows.ps1 | iex"
   ```
   Скрипт скачивает ZIP без пометки «скачано из интернета» (поэтому SmartScreen не
   останавливает неподписанную сборку), сверяет SHA-256 с `SHA256SUMS.txt` и запускает
   установщик.
2. **Вариант с ZIP:** скачайте `MacWin-windows-x64.zip`, полностью распакуйте его в отдельную
   папку и запустите `install.cmd`.
3. Установщик размещает программу в `%LOCALAPPDATA%\Programs\macwin`, добавляет
   MacWin в меню «Пуск», включает автозапуск в фоне (без окна) и открывает окно MacWin.
   Запрос администратора нужен для правил брандмауэра, не для постоянного запуска программы.
4. **Без установки:** `MacWin-windows-x64.exe` запускается двойным кликом — откроется окно
   MacWin, а значок появится в области уведомлений. При скачивании браузером SmartScreen
   может предупредить: «Подробнее» → «Выполнить в любом случае».
5. Если запрос брандмауэра отклонён, сопряжение может не работать. Не решайте это
   отключением защиты или запуском всего приложения от администратора.

Тестовые сборки не подписаны для распространения. Не отключайте защиту ОС целиком;
пользуйтесь командами установки выше.

## 3. Мастер первого запуска: роли, расстановка и код

**MacBook — основной**

1. Откройте MacWin. В окне «Каким будет этот компьютер?» выберите **Основной**.
2. Экран «Где стоит второй компьютер?» показывает мониторы MacBook так же, как
   **Системные настройки → Мониторы**. Перетащите прямоугольник **Windows-ноутбук**
   туда, где он стоит на столе — например, слева от встроенного дисплея, под большим
   монитором. Он примагнитится к ближайшему краю, а жёлтая линия покажет, где курсор
   будет переходить между компьютерами. Нажмите **Далее**.
3. Откроется шаг «Введите код со второго компьютера».

**Windows — вторичный**

4. Откройте MacWin (меню «Пуск» или значок в трее) и выберите **Вторичный**.
   Появится код вида `482-913`.
5. Введите этот код на MacBook и нажмите **Подключить**. Если компьютер не найден
   в сети, раскройте **Указать адрес вручную** и введите адрес Windows — он показан
   под кодом на Windows, например `192.168.1.20:47800`. Это обход поиска, но не сетевой изоляции.
6. Оба окна покажут «Готово! Компьютеры связаны.», затем статус «Подключено к …».
   Код действует 10 минут и на одну попытку; после неверной попытки Windows покажет
   новый код.

Расстановку можно менять в любой момент на вкладке **Расстановка** основного
компьютера; после первого подключения там видны реальные экраны Windows. Вторичный
получает расстановку автоматически, поэтому мышь Windows тоже переходит на Mac через
тот же край. Сторону на Windows выбирать не нужно.

## 4. Проверить обычный сеанс

Это список будущих ручных проверок; отмечайте только фактически выполненное.

- [ ] Курсор переходит на Windows только через подсвеченный в расстановке участок края
  и возвращается в ту же точку; через другие края перехода нет; клики и прокрутка работают.
- [ ] Текст набирается в обычном редакторе на втором компьютере; после возврата
  ни одна клавиша или кнопка мыши не остаётся зажатой.
- [ ] **Ctrl+Alt+Shift+Esc** возвращает управление и ставит обмен на паузу.
  На Mac это **Control+Option+Shift+Esc**. Кнопка **Продолжить** возобновляет обмен.
- [ ] При включённом **Общий буфер обмена** (вкладка **Буфер обмена**) текст и картинка
  копируются в обе стороны.
- [ ] Небольшой файл копируется через Finder/Explorer в обе стороны и открывается
  после вставки с исходным содержимым.
- [ ] **Пауза** и **Выйти из MacWin** освобождают управление. После повторного открытия
  не требуется новое сопряжение.
- [ ] Закрытие окна оставляет MacWin работать в строке меню / трее; **Открыть MacWin…**
  в меню значка (на Windows — щелчок по значку) возвращает окно.
- [ ] После краткой потери сети и перезапуска партнёра соединение восстанавливается.
- [ ] **Запускать при входе в систему** проверено после повторного входа в обе системы:
  MacWin стартует в фоне, без окна.

Парольные поля с macOS Secure Input и защищённые экраны Windows не используйте
как тест обычной клавиатуры: это известные ограничения текущей версии.

## Если что-то не работает

Сначала верните локальное управление аварийным сочетанием или своей мышью,
затем закройте MacWin на обоих компьютерах. Не отправляйте содержимое буфера,
одноразовые коды или ключи при описании ошибки.

Для диагностики нужны: версия/коммит сборки, версии ОС, архитектура Mac,
пункт списка выше и точный текст ошибки. Журналы:

- Mac: `~/Library/Logs/macwin/macwin.log`.
- Windows: `%LOCALAPPDATA%\macwin\macwin.log`.

Перед передачей журнала проверьте его на личные сведения и адреса сети.
Подробные CLI-команды и настройки: [README](README.md#usage).
